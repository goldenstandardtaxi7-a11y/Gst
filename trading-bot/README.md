# Търговски бот (стартова версия)

Автоматичен бот, който търгува борсово търгувани фондове (ETF) в САЩ чрез брокера
[Alpaca](https://alpaca.markets) в **дълги и къси позиции**: купува фондове, които
растат, и продава на късо фондове, които падат. Работи с демо сметка (paper) и с
реални пари (live).

> ⚠️ **Важно.** Никоя стратегия не гарантира печалба. Резултатите от миналото не
> предсказват бъдещето. Влагай само пари, които можеш да си позволиш да загубиш.

## Как работи стратегията

Стратегията следва тренда. Параметрите са фиксирани предварително и не са
„донастройвани“ спрямо историята, защото така тестът изглежда добре, а реалната
търговия губи.

1. **Моментум:** гледа доходността за 1, 3, 6 и 12 месеца за всеки фонд
   (Moskowitz, Ooi & Pedersen, *Time Series Momentum*, 2012).
2. **Филтър за тренд:** държи фонд само докато цената му е над 200-дневната
   средна (Faber, *A Quantitative Approach to Tactical Asset Allocation*, 2007).
3. **Размер по риск:** по-спокойните фондове (облигации) получават по-голям дял,
   по-нестабилните (акции) по-малък. Целта е всяка позиция да носи сходен риск.
4. **Къси позиции:** същите правила наобратно. Ако фондът пада и на 1–12 месеца,
   и е под 200-дневната си средна, ботът го продава на късо и печели от спада.
5. **Диверсификация:** 10 фонда: акции от САЩ и света, облигации, злато,
   недвижими имоти, суровини.

## Защити

| Защита | Стойност |
|---|---|
| Макс. дял в един фонд (дълга позиция) | 20% |
| Макс. дял в един фонд (къса позиция) | 10% |
| Общо в къси позиции | до 50% |
| Ливъридж | няма (дълги + къси ≤ 100% от капитала) |
| Къси само при фондове, които брокерът дава лесно назаем | да |
| **Kill switch:** спад от върха | −20% → продава всичко и спира |
| Макс. една поръчка | 25% от капитала |
| Минимална промяна за сделка | 2% (за да не плаща такси напразно) |
| Резерв в брой | 2% |
| Реални пари | само с `CONFIRM_LIVE=I_UNDERSTAND_THE_RISK` |

Всички стойности са в `tradingbot/config.py`.

### Защо къси позиции имат по-малки лимити
При дълга позиция най-много губиш вложеното. При къса загубата няма таван: ако
цената се удвои, губиш двойно. Затова една къса позиция е най-много 10% от
капитала, а щом трендът се обърне, ботът я затваря.

### Изисквания за къси позиции в Alpaca
- **Маржин сметка с поне $2 000.** Без нея ботът пропуска късите позиции и
  търгува само дълги.
- Къси се правят само с **цели акции**, без дробни.
- Ако един фонд трябва да мине от дълга в къса позиция (или обратно), ботът
  затваря позицията същия ден и отваря обратната на следващия.
- Заемането на акции струва пари. В теста се смята по 0,5% годишно.

## Инсталация

```bash
cd trading-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # попълни API ключовете
```

## Стъпки (по ред, не прескачай)

**1. Тест на история (backtest)**
```bash
python -m tradingbot backtest --start 2010-01-01
```
Сравнява стратегията с „купи и дръж SPY“. С `--no-shorts` виждаш как би се
справила само с дълги позиции. Така проверяваш дали късите изобщо помагат. Гледай основно `max_drawdown`
(най-големия спад). Можеш ли да изтърпиш такъв спад с реални пари?

**2. Демо сметка (поне 1–3 месеца)**
```bash
python -m tradingbot trade --dry-run   # само показва поръчките
python -m tradingbot trade             # праща ги в демо сметката
```
Пускай веднъж дневно, докато борсата е отворена (16:30–23:00 българско време).
Автоматично с cron, например в делник в 17:00:
```
0 17 * * 1-5 cd /път/до/trading-bot && .venv/bin/python -m tradingbot trade
```

**3. Реални пари.** Едва когато демото се държи както очакваш:
- в Alpaca отвори live сметка и вземи **нови** live ключове;
- в `.env`: `TRADING_MODE=live` и `CONFIRM_LIVE=I_UNDERSTAND_THE_RISK`;
- започни с малка сума.

Ако kill switch-ът се задейства, ботът спира. След като прегледаш какво е станало:
`python -m tradingbot reset-halt`.

Логовете са в `logs/bot.log`.

## Ограничения на стартовата версия
- Търгува само ETF, без отделни акции, опции и ливъридж.
- Данните идват от безплатния IEX поток на Alpaca.
- Възможни следващи стъпки: анализ на новини и настроения, повече пазари
  (крипто), известия по имейл или Telegram, уеб табло.
